## About

WoW Lab is a World of Warcraft simulation and planning platform. This organization is where we publish the open source tools we build along the way.

## Projects

| Repository                                                       | Focus                                                        |
| ---------------------------------------------------------------- | ------------------------------------------------------------ |
| [`addon`](https://github.com/wowlabdev/addon)                    | Companion addon for WoW Lab                                  |
| [`addon-releases`](https://github.com/wowlabdev/addon-releases)  | Packaged releases of the WoW Lab addon                       |
| [`blit-js`](https://github.com/wowlabdev/blit-js)                | JavaScript and React tools for game-asset rendering          |
| [`boardkit`](https://github.com/wowlabdev/boardkit)              | Multiplayer whiteboard and diagram tools for React           |
| [`eslint-config`](https://github.com/wowlabdev/eslint-config)    | Composable ESLint flat configs for JavaScript and TypeScript |
| [`language-tools`](https://github.com/wowlabdev/language-tools)  | RAL editor tooling and language support                      |
| [`markupwright`](https://github.com/wowlabdev/markupwright)      | Template-driven workspace documentation generator            |
| [`rulewright`](https://github.com/wowlabdev/rulewright)          | Executable engineering standards for Rust workspaces         |
